# Version 2 changelog

- Added a two-operator sine FM voice driven by MIDI note-on/note-off.
- Added FM ratio, FM index, and FM mix processing.
- Improved normalized parameter handling and beat-division mapping.
- Added 100 `.vstpreset` container candidates plus editable JSON recipe backups.
- Added a neon-dark interface design concept in SVG and PNG.
- Updated plugin version metadata to 2.0.0.

## Validation status
The source and preset containers are provided for SDK-side validation. This environment does not have the Steinberg VST3 SDK installed, so no compiled binary or DAW validation is claimed. The UI artwork is a design reference; it is not yet embedded as a custom editor view.
